The answer was never the hard part

Ask one model how to build something and it will tell you. Confidently. What it will not tell you is which assumption it quietly made on your behalf, or which decision you have not realised you are about to make.

Council AI is built around that gap. Every run ends with Decide these — the questions you did not think to ask, ordered by how much depends on them.

How it works

1

Five models, five instructions

The same question goes to five models at once — each given a conflicting brief. One optimises for shipping this week. One assumes the premise is wrong. One asks what nobody has accounted for.

2

One merges them

A sixth model reads every proposal and resolves the contradictions instead of averaging them. Where two models disagree, it picks and says why the other loses.

3

Then they argue

A Drafter writes the plan, a Critic on a different vendor attacks it, the Drafter revises. Three rounds. A Judge rules. A model cannot see the blind spots that produced its own flaws — so it never reviews itself.

Why five and not one

Four models given an identical prompt return four similar answers, and merging those produces mush. So they are told to disagree. This is a real run, unedited.

“I want to build a habit tracker app. What should I build first?”

Pragmatistgroq · gpt‑oss‑120b

Ship a single‑page web app with localStorage and persist it in the browser. Host on Netlify, free, today. No build tools, no backend, no authentication — literally three files.

Contrariancerebras · qwen‑3.8‑27b

Don’t build a tracker. Build a retention engine. 99% of habit apps fail on churn, not features. Your beautiful grid is a dead artifact if the user never returns on day four.

Same question. Same second. Opposite advice. The merge keeps what survives contact with the other.

Three depths

Quick

~40 seconds

Five models in parallel, then a merge. For a question you want a real answer to now.

Most used

Debate

~4 minutes

Drafter versus Critic across three rounds, then a verdict. For a plan that has to survive scrutiny.

Full

~7 minutes

Quick, then the debate runs on the merged plan. For decisions you will live with for months.

It remembers your projects

Point Council at a folder of markdown notes — an Obsidian vault is exactly that — and it searches them before every run. Stop pasting the same context into every prompt.

Every run shows precisely which notes it used. Private folders are never indexed. Nothing leaves quietly.
